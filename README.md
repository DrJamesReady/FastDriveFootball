# FastDriveFootball
Enhancement utilities to the Fast Drive Football Cards and Dice Game developed by 3dGaming, LLC. The purpose of these enhancements is to add 'immersive flavor' to the game experience while providing tools for the game player to create team cards.

## Team Card Card Maker

This .html file allows a player of the Professional version of **Fast Drive Football** to - 
- Enter league and season information
- Enter team information, and adjust colors of team name using RGB indicators
- Switch on/off offensive and defensive quality colors for the screen and print
- Add coach information
- Select, via pull-down menu, offensive and defensive qualities
- Enter field goal (FG) and extra-point (XP) ranges
- Add qualities related to the Commissioner Expansion 1.5

An example .json file (CFL_2026_team_cards.json) is provided. The .json file contains 16 teams from a fictional Carolina Football League (CFL). This file can be imported into the .html utility. Also availble is the .pdf output (FDF-CFL-2026 Teams.pdf) from the utility, create through the Print/Save As PDF option in Windows.
